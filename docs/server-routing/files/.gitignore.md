# .gitignore

Git이 실행 산출물·환경 파일·로컬 runtime을 추적하지 않도록 하는 저장소 규칙 파일이다. 코드 함수·메서드·파라미터·반환값은 없고 Git의 패턴 해석기가 직접 읽는다. 기존 사용자 규칙은 유지했다.

실제 기존 패턴은 `.venv/`, `__pycache__/`, `*.py[cod]`, `.env`, `.env.*`, `!.env.example`, `env.macos.sh`, `env.windows.ps1`, `kafka-data/`, `*.log`, `**/data/`, `infra/runtime/`, `*.crc`, `*.delta`, `*.parquet`, `data-window-demo/`다. 값의 출처·쓰기 소유자는 저장소의 .gitignore다. 런타임 비밀값을 이 문서에 기록하지 않는다.

24일차 경로 정정에서 `**/data/` 뒤에 아래 한 문서의 경로만 다시 포함하는 규칙을 추가했다. 부모를 열고 다른 하위 항목은 다시 제외한 뒤 정확한 파일을 허용한다.

```gitignore
!docs/server-routing/files/data/
docs/server-routing/files/data/*
!docs/server-routing/files/data/exports/
docs/server-routing/files/data/exports/*
!docs/server-routing/files/data/exports/player-cdc.ndjson.md
```

의사코드: `실제 data 폴더 제외 → 짝 문서의 data/exports 부모만 통과 → 지정한 player-cdc.ndjson.md만 추적 가능`. 실제 `data/exports/player-cdc.ndjson`, 기존 환경 파일, 임시 data 산출물은 계속 제외된다. Git index를 직접 변경하거나 stage하지 않는다. `git check-ignore`로 실제 데이터 제외와 문서 허용을 검증한다.
