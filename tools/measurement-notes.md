## run-20과 run-50 관찰 결과

- 두 실행은 30초, 계정별 최소 1초 간격, 단일 ASGI 프로세스, 한 계정당 미완료 명령 한 개 조건을 유지했다.
- `run-20`: 요청 20명 / 연결 성공 20명 / 최고 동시 연결 20명, 성공 600건, 오류 0건, 처리율 약 19.988건/초, RTT p95 약 340.282ms.
- `run-50`: 요청 50명 / 연결 성공 48명 / 최고 동시 연결 48명, 성공 1,484건, 오류 2건, 처리율 약 48.713건/초, RTT p95 약 500.036ms.
- 요청 계정 수는 입력 조건, 연결 성공 수는 로그인과 WebSocket 연결을 마친 계정 수, 최고 동시 연결 수는 관찰 중 동시에 열린 연결의 최댓값이므로 서로 같은 의미가 아니다.
- 50명 실행은 20·20·10명으로 요청했고 실제 연결은 `load18-01` 18명, `load18-02` 20명, `load18-03` 10명이었다. 첫 방의 연결 실패 2건과 오류 2건을 결과로 유지한다.
- 처리율과 p95가 함께 증가했다. 이 결과만으로 MySQL, 서버 처리, 방 방송, 측정 도구 중 하나를 원인으로 확정하지 않는다.
- 현재 교실 구성에서 관찰한 동시 연결 최댓값은 48개다.
- 이 결과의 행동 조건은 계정당 최소 1초 간격과 단일 미완료 명령 방식이다.
- 다른 장비·다중 프로세스·더 빠른 전투는 별도 측정과 구조 변경이 필요하다.
